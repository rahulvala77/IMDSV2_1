# IMDS v2.0 roadmap

1. Inspect and preserve the current v1.0 project and inputs.
2. Implement and test daily technical history collection.
3. Discover/download official filings and archive raw documents.
4. Extract annual, quarterly and shareholding facts with traceable source metadata.
5. Calculate valuations; handle banks and NBFCs with sector-appropriate metrics.
6. Implement validation, scoring, ranking and risk flags.
7. Backtest using historical data while addressing survivorship bias.
8. Generate Excel reports and complete one-command orchestration.

A stage is complete only after tests and sample reconciliation pass.
